# MediaLife — сайт компании

Лендинг технической поддержки мероприятий: звук, свет, видео, LED-экраны и сцены.

Сайт статический: HTML, CSS и JavaScript. GitHub Pages не используется. Файлы выкладываются на обычный хостинг и открываются на вашем домене.

## Как выложить на домен

Домен — это адрес. Файлы сайта должны лежать на хостинге (Beget, Timeweb, REG.RU, Selectel и т.п.).

1. В панели хостинга привяжите домен к сайту (корневая папка обычно `public_html` или `www`).
2. Загрузите в корень сайта файлы:
   - `index.html`
   - `404.html`
   - `favicon.svg`
   - `.htaccess`
   - папки `css/` и `js/`
3. В DNS домена укажите NS-серверы хостинга **или** A-запись на IP хостинга.
4. Включите SSL (Let's Encrypt) в панели хостинга — `.htaccess` переведёт посетителей на https.

Если пришлёте сам домен и где он зарегистрирован / какой хостинг — пропишу адрес в мета-тегах и проверю настройки.

## Как открыть локально

```bash
python3 -m http.server 8080
```

Адрес: http://localhost:8080
