# MediaLife — сайт компании

Лендинг технической поддержки мероприятий: звук, свет, видео, LED-экраны и сцены.

## Почему так, а не иначе

Для этого репозитория лучший вариант — **статический HTML + CSS + JS на GitHub Pages**.

| Подход | Когда брать | Почему не для нас сейчас |
| --- | --- | --- |
| **HTML / CSS / JS + GitHub Pages** | Сайт компании: услуги, оборудование, заявка | Это наш выбор: бесплатно, уже настроено, быстро грузится, нет сервера |
| Next.js + админка + база | Каталог, который вы сами правите каждый день, заявки в кабинете | Не работает на GitHub Pages, нужен Vercel и база, сложнее сопровождать |
| Tilda / WordPress | Если тексты правите только вы, без агента | Лишняя платформа, этот репозиторий уже заточен под Pages |

Сервер и база не нужны, пока нет личного кабинета и ежедневного каталога на 100 позиций. Заявки уходят письмом через почтовую программу. Когда понадобится приём заявок без почты — подключим Telegram-бота или Formspree, стек менять не придётся.

Сайт: **https://vecherb-spec.github.io/site/**

## Что на сайте

- Главная с оффером
- Услуги: звук, свет, видео/LED, сцены
- Оборудование по категориям
- О компании и этапы работы
- Форма заявки и контакты

## Как открыть локально

```bash
python3 -m http.server 8080
```

Адрес: http://localhost:8080

Файл `index.html` лучше не открывать двойным щелчком — часть путей может работать некорректно.

## Как опубликовать

После слияния в `main` GitHub Actions сам выкладывает сайт на Pages.

Если Pages ещё не включены: **Settings → Pages → Deploy from a branch → main / (root)**.
