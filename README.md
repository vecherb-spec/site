## Яндекс Директ

На сайте уже есть то, что модерация обычно проверяет у посадочной:

- HTTPS, телефон в шапке, форма заявки, Telegram
- политика конфиденциальности: `privacy.html`
- неотмеченный чекбокс согласия у формы
- cookie-уведомление про Метрику
- реквизиты ООО «МЕДИАЛАЙВ» (ИНН 9714076643, ОГРН 1257700258144)
- новый основной счётчик Метрики для `medialive.tech` задаётся в `js/site-config.js` (`metrikaId`)
- страница конверсии `thanks.html`

**Что сделать в кабинетах Яндекса (без этого реклама не поедет):**

1. [Метрика](https://metrika.yandex.ru/) → создать новый счётчик в аккаунте Яндекс Директа → **Адреса сайта**: `https://medialive.tech/`.
2. Вписать ID нового счётчика в `js/site-config.js` → `metrikaId`.
3. Создать JavaScript-цели с точными идентификаторами: `quiz_submit`, `phone_click`, `telegram_click`, `max_click`.
4. Цель «Посещение страницы»: `https://medialive.tech/thanks.html` — только если она нужна в стратегии отдельно от квиза.
5. [Вебмастер](https://webmaster.yandex.ru/) → добавить `medialive.tech`, код подтверждения вписать в `js/site-config.js` в `yandexVerification`.
6. Карточка в [Яндекс Бизнесе](https://business.yandex.ru/) с телефоном и адресом.
7. Директ: кампания на `https://medialive.tech/`, привязать новый счётчик, стратегия «Максимум конверсий» по цели `quiz_submit`.
8. Заменить `maxUrl` в `js/site-config.js` на точную ссылку чата MAX, когда она будет известна.
9. Маркировка рекламы (ОРД / токен в объявлениях) — это в кабинете Директа, не на сайте.
